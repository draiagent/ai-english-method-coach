# CSV 字庫規格

## 必要欄位

| 欄位 | 說明 |
|---|---|
| `單字` | 英文單字或詞組；同一資料集內作為穩定 Card ID 的主要來源 |
| `中文定義` | 正體中文定義 |
| `詞性` | 例如 `noun`、`verb`、`adjective` |
| `例句` | 英文例句，可在同一儲存格下一行加入中文翻譯 |

## 選填欄位

| 欄位 | 說明 |
|---|---|
| `星級` | 1–5 的整數 |
| `分數區間` | 教材自訂的程度或分數標籤 |
| `分類` | 例如辦公日常、溝通互動、金融與會計 |
| `【詞性變化】` | 可用逗號或分號分隔 |
| `搭配詞` | 常見 Collocations，可用逗號或分號分隔 |
| `核心意象` | 七步教練的可靠概念提示 |
| `句型結構` | 例句拆解提示；缺少時介面不會自動編造 |
| `任務提示` | 可供心智圖或情境任務使用 |
| `程度` | `beginner`、`elementary`、`intermediate`、`advanced` |

## 正規化規則

- 欄位名稱會去除前後空白。
- 單字會轉為小寫並合併連續空白，以產生穩定 Card ID。
- 同一資料集內重複單字只保留第一筆，並回報略過列數。
- 缺少必要欄位的資料列會略過，不會補造內容。
- 使用者字庫的 Dataset ID 由檔名正規化產生。

## 最小範例

```csv
單字,中文定義,詞性,例句
inform,通知；告知,verb,"Please inform the manager.
請通知經理。"
```
